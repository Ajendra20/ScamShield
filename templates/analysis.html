How ScamShield Checks Payments

🔴 Known Demo Identifier

If the receiver matches a synthetic identifier in the local SQLite database, ScamShield flags it for this demonstration.

🟡 Amount Review

If no identifier match exists and the amount is ₹25,000 or more, the system recommends independently verifying the receiver before paying.

🟢 No Known Demo Match

If neither rule triggers, the system reports no known demo match. This does not guarantee that the receiver is safe.
