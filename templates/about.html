About ScamShield

ScamShield is a student project designed to demonstrate how online payment risks can be checked before a user proceeds with a payment.

Our Objective

To help users identify known demonstration identifiers and recognize situations where additional verification is recommended.

Key Features

  • Payment receiver identifier checking
  • Amount-based verification warning
  • SQLite database for sample records
  • Analysis dashboard
  • Dataset viewing page
  • Simple and responsive user interface

Technology Used

Python Flask SQLite HTML CSS

Limitations

This prototype uses synthetic records and predefined rules. It does not connect to bank systems, verify live scam reports, or guarantee that a payment is safe. It does not currently use a trained machine learning model.
